プライバシーポリシー

最終更新日: 2026年11月8日

yt-shorts-uploader（以下「本ツール」）は、チャンネル所有者本人が、自分で制作した動画を自分の YouTube チャンネルに投稿するための非公開ツールです。本ツールは YouTube API Services を利用しています。

1. 取得する情報

  • Google の OAuth 認証で発行されるトークン（スコープ: https://www.googleapis.com/auth/youtube.upload）
  • 投稿した動画の ID（投稿の記録のため）

本ツールは、チャンネル所有者以外の利用者の個人情報、視聴者のデータ、チャンネルの統計情報を取得しません。

2. 利用目的

取得した情報は、チャンネル所有者が制作した動画を、そのチャンネルにアップロードするためだけに使います。

3. 保存と共有

  • トークンは、チャンネル所有者が管理する GitHub リポジトリの暗号化されたシークレットにのみ保存します。
  • 取得した情報を第三者に販売・提供することはありません。

4. 許可の取り消し

本ツールへのアクセス許可は、Google アカウントのセキュリティ設定からいつでも取り消せます。取り消すと、本ツールは投稿できなくなります。

5. YouTube と Google のポリシー

本ツールの利用には、YouTube 利用規約が適用されます。Google による情報の扱いについては、Google プライバシーポリシーをご覧ください。

6. お問い合わせ

このサイトの GitHub リポジトリの Issues からご連絡ください。
